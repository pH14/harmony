# Conditional control from one verified encounter

E01 supplies a reproducible Ridley-context state with decoded health 79 and no
missiles. The immediate question is whether the existing independent controller
law can produce a surviving damage endpoint from this actual state. A negative
cannot distinguish inadequate resources from inadequate control, prove inability
to fight, or describe other campaign states. No resource injection, route or
scripted fight is allowed. This is a diagnostic, excluded from fresh validation.

Use 32 frozen trial seeds. Generate 128 commands per seed with the unmodified
`sample_chord` implementation, before emulator execution. Pair each sequence with
all-buttons-released commands having identical hold durations. The passive arm
controls for inherited motion, projectiles and automatic transitions; it is not
a competitive search policy. Balance arm order by trial index. Its paired results
support conditional descriptions only, without independent-sample power claims.

Restore exactly the same verified positive snapshot before every trial. Check
mechanical state, raw boss context and serialized snapshot equality after each
restore, without advancing a frame. Start a fresh HP baseline and epoch. Execute
commands one physical frame at a time for same-boundary observation, at most
8,192 continuation frames and 128 original commands per arm. Do not start a
command if it cannot fit in the remaining frame budget. Stop on corrected death,
game ending, leaving the starting area or a surviving defeat endpoint. A brief
unclassified boss context alone is not area exit or proof of defeat. One-frame
terminal stopping has different post-death work from held-action campaigns;
report actual diagnostic frames and make no campaign-throughput comparison.

A primary local success requires a guarded HP decrease within an original held
command, a live endpoint at that command's end, the same visible boss identity,
and lower HP at the endpoint than at that command's start. Death in the same
command does not qualify. Reset, gap, unclassified/changed identity, unavailable
HP and unexplained increases cannot manufacture progress. Matching visible
identity still does not rule out an invisible same-key reload; report observed
changes, not exact lifetime damage. Keep per-frame drops, surviving endpoint
successes and defeat flags distinct.

Save the first surviving damage input and first surviving defeat input per arm
(at most four tapes). Each concatenates the existing searched prefix and the
executed new commands. Replay each twice from ordinary genesis with the original
held-action cadence, requiring matching live mechanical state, raw context and
emulator bytes. This qualifies the produced endpoint, not a fresh search result.
The passive comparator must also be reported, including any apparent progress
caused without new button presses. No local result alone establishes a global
retention or selection bottleneck.

First run inexpensive planted checks for dying within the damage command,
missing/reloaded context, pending progress before the current command, exact
passive duration preservation and budget admission. Then freeze source, builds,
assets, the complete seed list, generated suffix hash, wall/process/output and
actual frame ceilings before native work. A single setup plus 64 bounded trials
costs at most 643,092 frames under the current 118,804-frame setup. At most eight
held witness replays add at most 1,015,968 frames. Reserve a separate 2M auxiliary
block for this diagnostic, with a ten-minute process cap and bounded output.
No second seed list, tuned action law or larger global search follows automatically.
