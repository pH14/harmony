# Hardware-RNG (rdrand/rdseed) per-site allowlist for the fault-library guest
# kernel, the task-park build (FAULTLAB=1 ./build-kernel.sh) under
# the pinned nix toolchain;
# the other kernels' baseline is rdrand-allowlist-gha.txt. Every entry is a site the
# review confirmed sits
# behind an X86_FEATURE_RDRAND / X86_FEATURE_RDSEED check: the frozen CPUID
# (stock virtual_time composition) hides both features, so a checked site is
# dead code in the image; an unchecked site would execute natively (SVM cannot
# intercept the instruction) and feed true entropy no contract can replay.
# Selected by build-kernel.sh whenever the profile is built; it wins over
# HARMONY_RDRAND_ALLOWLIST because that names a list captured from another
# configuration.

# extract_entropy's block loop tries arch_get_random_seed_longs (rdseed) then
# arch_get_random_longs (rdrand). Each is reached only through an
# .altinstr_aux testb on boot_cpu_data's RDSEED / RDRAND capability bits.
vmlinux:extract_entropy.constprop.0+0xa2
vmlinux:extract_entropy.constprop.0+0xb5

# random_init_early's seeding loop, same seed-then-random inline pair, same
# capability-bit gating.
vmlinux:random_init_early+0x55
vmlinux:random_init_early+0x69

# The RDRAND self-test; it returns unless cpu_has(c, X86_FEATURE_RDRAND)
# (test $0x40000000 on the feature word).
vmlinux:x86_init_rdrand+0x1b
