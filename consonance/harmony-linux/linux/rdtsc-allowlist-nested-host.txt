# Nested-host x86 counter baseline for GCC 14 / Linux 6.18.35 with both KVM vendors.
# Reviewed against the pinned source and compiled KVM archive. KVM host
# RDTSC/RDTSCP inputs have been replaced with intercepted IA32_TSC RDMSR.
# No native counter opcode remains in arch/x86/kvm/built-in.a.
#
# The remaining sites inherit the ordinary guest's frozen CPU, boot and
# workload scope. This list does not claim a stock-KVM RDTSC trap. Raw fallback
# branches must remain inactive, or their results must be discarded, in the
# Harmony guest. Setup and decompressor remain subject to the raw-byte scan.
#
# GCC 14 emits quick_pit_calibrate out of line. native_calibrate_cpu_early
# calls it only when CPUID and the frequency MSR report nothing, and the pinned
# CPUID contract always reports a frequency. random_get_entropy compiles to the
# clock-page read alone, so its entropy callers carry no counter read. Relative
# offsets are specific to this configuration.

# .altinstr_replacement: ordinary counter alternatives; KVM host accessors contain none.
# Enabling KVM_AMD shifts 22 sites by 0xfd. Their alternative records retain
# the same originating function/offset, feature guard, and original/replacement
# bytes as the VMX-only binary. The origins are read_tsc, check_tsc_warp,
# trace_clock_x86_tsc, pvclock_clocksource_read{,_nowd}, delay_tsc and delay_halt.
