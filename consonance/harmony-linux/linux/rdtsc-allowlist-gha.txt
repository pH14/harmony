# Counter-read (rdtsc/rdtscp) per-site allowlist for the guest kernel as built
# by the GitHub-hosted ubuntu-24.04 runner toolchain (default gcc 13).
#
# The box baseline in rdtsc-allowlist.txt is for an earlier patch series and
# a different toolchain. Its per-function review classes still apply, with
# quick_pit_calibrate carrying the former native_calibrate_cpu_early reads.
# Offsets and inlining are toolchain-dependent.
#
# Regenerate when the runner toolchain moves or the patch series changes: the
# scan failure prints the unlisted/stale sites in paste-ready form; review
# each site against the disassembly and source before committing.
# Last re-baseline: mandatory CONFIG_HARMONY_PVCLOCK folded runtime branches
# in entropy, sched-clock, syscall, and alternative-instruction code. The
# eliminated reads were former fallback paths. PIT calibration reads move
# from native_calibrate_cpu_early to quick_pit_calibrate after inlining; the
# fixed Harmony CPUID leaf 0x15 supplies frequency before that fallback.
# The current image has 104 reviewed reads; all retained reads trap to the
# deterministic counter oracle under the Harmony CPU contract.
# Selected by build-kernel.sh via HARMONY_RDTSC_ALLOWLIST (the x86-vtime
# workflow sets it).
