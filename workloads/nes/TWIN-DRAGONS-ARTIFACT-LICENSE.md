# Twin Dragons artifact notice

Gameplay recordings and images in this artifact were generated by Harmony from
**Twin Dragons** by Garydos, pinned at commit
[`bcf27d0c5117a2aac19e6c33bdb3c776ada069fb`](https://github.com/Garydos/twin-dragons-nes/tree/bcf27d0c5117a2aac19e6c33bdb3c776ada069fb).

This is an altered build. Harmony zeroes the game's sound-effect data, so the
recordings contain no sound effects. The sound effects are by Shiru and the
upstream README reserves all rights to them. No other ROM byte is changed.

  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- The FamiTone2 audio library is by Shiru and FamiTone5 is by nesdoug. Both are
  public domain.

The recordings use the source-built QuickNES libretro core pinned in
`scripts/build-quicknes-core.sh`. The reproducible ROM recipe is
`workloads/nes/scripts/build-twin-dragons-rom.sh`.
