# nes-busybox startup eager-binding proposal
ELF SHA256 a01efe4809a7c53dcc69c6360520f4f78eec8ec58166c4f67d9ff30188cfb546. Exact _dl_non_dynamic_init writes _dl_lazy at 0x484ceb; dl_open_worker_begin reads it at 0x4dee9d. Patched Ubuntu glibc2.39 elf/dl-support.c:310 initializes _dl_lazy to whether startup LD_BIND_NOW is missing/empty. elf/dl-open.c:676-679 adds RTLD_LAZY only if _dl_lazy is nonzero. Nonempty LD_BIND_NOW=1 before startup therefore sets zero and suppresses lazy relocation, including an ordinary later dlopen requested with RTLD_LAZY. Environment changes afterwards do not reinitialize that global; each exec needs the launch invariant.

The _dl_relocate_object lazy test skips resolver GOT installation; neither resolver is directly called elsewhere in the inspected code. IFUNC remains executable and is covered by the complete scan. Static linking alone, and the agent's NOW flag alone, are not the proof.
Fixed execution must exclude LD_PROFILE/LD_AUDIT/LD_PRELOAD/other loader overrides, unreviewed libraries, arbitrary internal function entry, generated code and mutation. Both exact ELFs have no TLSDESC relocations and no separate descriptor save sites; eager binding is not asserted to exclude hypothetical TLSDESC paths.
