# _dl_relocate_object compiled-object differences
The raw comparison intentionally retains differences outside relocation fields; none are silently masked. Offsets are relative to _dl_relocate_object.
BusyBox offsets0xf2..0xf4 and0x630..0x632: object R_X86_64_REX_GOTPCRELX references to weak _dl_rtld_map load its address from the GOT for cmp; static linker replaces them with cmp immediate0 against r10/r12. The symbol is undefined weak and resolves to zero in this static ELF. The agent retains GOT references and does not have these opcode differences.
Both binaries offsets0xf68..0xf69 and0x2a56..0x2a57: object R_X86_64_GOTTPOFF references __libc_errno using mov GOT-relative TLS offset; static linker replaces this with mov immediate TLS offset (-32 BusyBox, -64 agent) into rax. Corresponding relocations are recorded in libc-object-correspondence.json and object/linked disassembly is retained. These changes are outside the prefix containing the lazy branch and GOT resolver installation. No blanket equivalence for unrelated functions is asserted.
