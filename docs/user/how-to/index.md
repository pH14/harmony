# How-to guides

Choose the task you need to complete. Each guide states its prerequisites and gives the steps to reach that result.

- [Install Harmony](install.md) — Build and install the CLI and guest runtime.

- [Run your OCI image](oci.md) — Choose an image, launch a command, and retain results.

- [Prepare a fault workload](fault-workload.md) — Describe your nodes and correctness checks.

- [Replay a failure](replay.md) — Re-run a recorded action list against the same inputs.

- [Add SDK assertions](sdk.md) — Report application properties from Rust or a checker script.

- [Search an NES workload](nes.md) — Run the game-specific search package.

- [Troubleshoot a run](troubleshooting.md) — Resolve setup errors and understand incomplete runs.
